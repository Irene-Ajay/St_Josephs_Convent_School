How this works

  1. Download the template below, or use your school's existing student list.
  2. Make sure there is a column for Admission Number and Name. Everything else is optional.
  3. Upload the file. Classes are created automatically from the Class and Division columns.

Uploading the same file again is safe. Students are matched by admission number, so existing records are updated rather than duplicated. To correct a mistake, fix the spreadsheet and upload it again.
